Fade King
 Fade King is a fast, single-page website built for a barber shop to solve a common problem: potential clients scrolling past a business with no real online presence. Instead of a slow, generic template, Fade King gives the shop a sharp, static site where visitors can see the barber's work in the gallery, know pricing upfront, read the shop's story, and find contact details all without a single loading delay. Built with HTML, CSS, and JavaScript, and deployed on Vercel.

 Live Site: client-webservice.vercel.app

What It Solves
1. No online credibility → the About section builds trust with the shop's story and identity
2. Unclear pricing/offerings → the Services section lays out exactly what's on offer
3. "Can I trust this barber?" → the Gallery gives visual proof of work quality
4. Hard to reach the shop → the Contact section makes location and booking info easy to find
5. Slow, clunky sites → built fully static, so it loads instantly on any device
   
Tech Stack:
1. HTML5
2. CSS3
3. JavaScript (vanilla)
